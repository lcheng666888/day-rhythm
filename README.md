# Day Rhythm · 日常有声

此目录是交付包的完整开发源码；日常使用请运行上一级 `artifacts/启动网页.cmd`。项目根目录 README 是交付入口。本目录包含本地 Git 固定提交，提交标识、源码快照、SHA-256 清单和最新核查记录位于上一级的 `evidence/`。

从源码重建成品：`node tools/build-delivery.mjs`。解析成品与源码：`python tools/parse_delivery.py`。检查实际服务：`node tools/check-http.mjs http://localhost:4173`。工具只使用 Node.js 和 Python 标准库，不需要第三方包。

奶油白、橄榄绿和三张原创黑胶封面组成的作息提醒网页。早晨每日起床提醒、午睡倒计时、每日睡前提醒，三种声音均为本项目原创合成。

当前版已重新设计整页字体与字号：正文、日期和主要操作 16px，辅助说明 14px，场景标题 28px，时间数字 36–40px，并加强文字对比度。手机端保持阅读字号，主要控件至少 44px，滚轮选项 48px。设计说明见 `docs/typography.md`。

## 运行

双击 `启动网页.cmd`，就绪后会自动打开浏览器。需要 Node.js 18+，无需安装依赖；脚本也会查找当前电脑已有的 Codex Node 运行时。也可在本文件夹运行：

```powershell
node server.mjs
```

默认打开 http://localhost:4173 ，以启动窗口显示的实际地址为准。重复启动时会识别并复用已有的同项目服务；如果端口被其他程序占用，会向后寻找空闲端口（最多 20 次），不会终止其他进程。切换端口后浏览器存储独立，之前的设置仍保留在原地址。不要直接双击 HTML：浏览器对本地文件的模块加载和存储限制会影响功能。同一个地址、端口和浏览器下会恢复设置。开发服务器监听所有本机网卡，手机与电脑在同一局域网时，可用电脑的局域网 IP 加实际端口访问；手机端请注意浏览器的声音授权。

## 使用

- 首次打开或刷新后点击「启用提醒声音」，也可直接试听。声音权限不会假装永久保存。
- 早晨和晚上均可选「仅这一次」或「每天重复」，用「今天」「明天」或日期选择器确定日期，再设置 24 小时时间、打开开关。默认关闭两个提醒，以免初次访问意外响铃。
- 单次提醒严格按所选日期执行，已过的日期或时间会提示改时间或选明天，不会自动跳日；响过或错过后自动关闭。每天重复以所选日期为开始日期，今天的时间已过则明确显示下一次有效日期。
- 时间可以直接输入 `HH:MM`，也可展开小时、分钟滚轮上下滑动。滚轮支持点击、↑ ↓、Home / End 和 PageUp / PageDown，和键盘输入实时同步。未填完整或无效的日期时间会保留为草稿，暂停该项调度，卡片显示修改提示。
- 卡片与页面下方显示同一触发时间的完整年、月、日、星期及时间。午睡显示预计结束时间，精确到秒；暂停后显示继续计时后的预计结束时间。
- 午睡输入 1–180 分钟或选择快捷时长，点击「开始午睡」。支持暂停、继续、重置；关闭午睡开关会暂停计时。
- 三个音量滑块分别控制各场景，试听时也可实时调整。设为 0% 表示静音。
- 所有设置自动保存，「保存设置」也可手动确认。减少动态效果遵循系统偏好，也可手动开启。
- 「使用指南」提供 10 秒真实午睡提醒体验、最近触发记录和可选的屏幕常亮。
- 按「停止」或 Esc 结束当前播放。多个提醒同刻到点会依次播放，停止一个后开始下一个。

## 播放与恢复规则

全页只有一个音频元素；试听、正式提醒使用相同音频、音量和唱片效果。播放器用序号处理异步播放竞争，旧的播放请求无法覆盖后来的选择。音频实际开始播放后，唱片才旋转、唱针才落下。播放失败时显示手动播放入口。切换和停止会暂停旧声音、重置进度并收回唱针。

晨间铃声是 18 秒渐强旋律，午后为 6 秒清脆提示，睡前为 16 秒舒缓音垫。试听播放一遍自动结束；正式提醒循环播放，最长分别为 90、45、40 秒，随时可停止。

午睡保存绝对截止时间，刷新不会重新开始。日期提醒使用设备本地日历构造时间，不通过 UTC 日期字符串转换。单次提醒保存具体日期和时间；每日重复从所选日期起计算。触发前先保存已消费的时间点，避免同一分钟重复。后台回来时补发 5 分钟内的提醒，更久则记录为已错过。刷新时未完成的提醒在 5 分钟窗口内保留，点击启用声音后继续。最近 30 条记录保存在本地，界面显示最近 10 条。旧版保存的每日提醒会自动迁移；跨午夜后「今天」「明天」的选中状态也会更新。

Web Locks 可用时，仅一个同源页面负责提醒；关闭该页面后，另一个页面会接手，但仍需在接手页面启用声音。不支持 Web Locks 的浏览器请只开一个页面。

## 后台与锁屏边界

**这是普通网页，不能替代系统闹钟。** 页面关闭、系统休眠和锁屏后，浏览器可能暂停脚本或阻止音频。后台计时也可能被节流。声音授权、屏幕常亮都不能保证锁屏后自动唤醒。

页面显示这一限制；支持的浏览器中可手动开启屏幕常亮，仅在页面可见时有效。未实现声称能离线唤醒的 Service Worker 或系统定时推送。真实后台测试结果和未验证平台见 `docs/verification.md`。

## 文件

- `index.html`、`styles.css`：页面与响应式唱片动画。
- `app.mjs`：设置、页面交互、声音授权、后台恢复、跨页面协调。
- `scheduler.mjs`：每日时间、倒计时、去重、延迟补发与数据校验。
- `reminder-editor.mjs`：日期、重复方式、键盘时间输入、可滑动滚轮与错误提示。
- `player.mjs`：单一播放器、切换竞争处理、停止和播放时限。
- `assets/*.png`：三张 ImageGen 原创封面；提示词见 `assets/art-prompts.md`。
- `assets/*.wav`：原创合成铃声与声音授权用静音片段。
- `assets/compose.py`：Python 标准库音频生成脚本，可重新生成音频文件。
- `tests/*.test.mjs`：不依赖外部包的调度和播放器测试。
- `docs/`：设计、验证结果与页面截图。
