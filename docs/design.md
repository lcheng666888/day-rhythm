# Day Rhythm 首版设计

单页、无第三方运行时依赖，以三张唱片表示一天的三段节奏。桌面三列，手机单列。封面为原创印刷质感插画，黑胶与唱针用 CSS 绘制。三段旋律由项目内 Python 脚本合成为 WAV，作为真实音频文件保存。

每日提醒使用本地日历，午睡使用绝对截止时间；每次触发先写入持久化状态再播放，避免同一分钟反复响铃。刷新后恢复设置和倒计时，声音授权需要再次点击。提醒延迟不超过 5 分钟时补发，超过则记为错过，避免几小时后突然响铃。同时到点的提醒排队，正式提醒优先于试听。多标签页由 Web Locks 保证单个页面响铃；不支持时提示只保留一个页面。

一个 HTMLAudioElement 负责所有试听与正式提醒；只有 play 成功后才启用对应动画，失败时显示可手动播放的提醒。晨间渐强旋律、午后木琴提示、夜间舒缓音垫。提醒最长播放 90 / 45 / 40 秒，支持手动停止。减少动态效果遵循系统偏好，并提供独立选项。

网页关闭、系统休眠、锁屏后的自动唤醒不在普通网页能力范围内。展示声音授权、后台提醒说明和可选的屏幕常亮；不宣称替代系统闹钟。检验真实短倒计时、每日提醒、刷新恢复、重复去重、播放器切换、后台和移动布局。
