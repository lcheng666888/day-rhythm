# 阅读体验与字体设计

## 字体分工

- 中文大标题与场景标题使用本地宋体字族，保留唱片封面的编辑感。
- 正文、按钮和表单使用苹方 / 微软雅黑 UI / 微软雅黑等本地黑体字族，提高连续阅读清晰度。
- 时间、倒计时和技术标签使用 Cascadia Mono / Consolas 等等宽数字字族，启用等宽数字，减少时间跳动。
- 封面英文使用 Georgia 斜体，作为画面的一部分。没有新增外部字体或 CDN，离线资源仍完整。

## 字号层级

| 位置 | 字号 |
| --- | --- |
| 页面标题 | 桌面 42–58px；手机 36–44px |
| 场景标题 | 28px |
| 时间输入、倒计时 | 40px；最窄手机 36px |
| 正文、主要按钮、日期、下次提醒 | 16px |
| 表单标签、次级操作 | 15px |
| 辅助说明、错误提示、音量数值、指南提示 | 14px |
| 装饰性唱片编号、英文标签 | 11–12px |

主要阅读文字保持 1.7–1.9 行高，文字颜色加深；不把功能性提示缩成 8–10px。小屏空间不足时优先换行，最窄屏幕的日期选择器占一整行。

## 控件与布局

主要按钮、日期快捷键、输入、开关和音量滑块均提供至少 44px 高的操作区域。时间滚轮的每行提高到 48px、数字 28px；编辑器从 CSS 自定义属性读取同一行高，保证滚动距离、键盘选择与选中值一致。

桌面保留三列唱片；较窄窗口采用宽松单列，避免为塞进三张卡片而缩小字号。手机保留相同正文尺寸。重写并分区组织样式表，移除了多轮互相覆盖的旧字号规则。

## 验证范围

检查 1440、1280、1024、768、390 和 320px 六个视口的字号、控件尺寸与横向溢出。实际检查键盘与滚动选择、提示与弹窗、试听和停止、减少动态、音量、倒计时、到点提醒与刷新恢复。

最新机器记录和截图在交付包 `artifacts/evidence/typography-check.json`、`browser-check.json` 和 `screenshots/`，功能测试继续使用原有完整调度、播放器与启动器测试。
